1. Was ist im Paket?

Datei / OrdnerWofür?
MPC Mapper.appDas Programm für den Mac
grandMA3-PluginPlugin fürs Pult, schon in der richtigen Ordnerstruktur für den USB-Stick – schickt den Status der Executoren an die App. Mit Kurzanleitung LIESMICH.txt

Du brauchst außerdem: einen APC mini mk2 (nicht das alte Modell) und ein grandMA3-Pult oder grandMA3 onPC im selben Netzwerk wie der Mac.

2. App installieren

  1. Prüfe, welchen Mac du hast: Apfel-Menü → Über diesen Mac. Steht bei „Chip“ Apple M…, brauchst du die Version apple-silicon, sonst intel.
  2. Die heruntergeladene ZIP doppelklicken – es entsteht ein Ordner.
  3. MPC Mapper.app in den Ordner Programme ziehen.
  4. App starten (Launchpad oder Programme-Ordner).
macOS blockiert die App beim ersten Start? Das ist normal, weil sie nicht von Apple signiert ist.
Öffne Systemeinstellungen → Datenschutz & Sicherheit, scrolle ganz nach unten und klicke bei „MPC Mapper“ auf „Dennoch öffnen“. Danach startet sie normal.
Fragt macOS, ob „MPC Mapper“ eingehende Netzwerkverbindungen annehmen darf: Erlauben. Sonst kommt vom Pult keine Rückmeldung an.

3. grandMA3 einrichten (einmalig)

Schritt 1 – OSC einschalten

Am Pult: Menu → In & Out → OSC. Dort Enable Input und Enable Output einschalten.

Schritt 2 – Zwei OSC-Lines anlegen

Die IP-Adresse deines Macs findest du unter Systemeinstellungen → WLAN (bzw. Netzwerk) → Details.

EinstellungLine 1 (Befehle)Line 2 (Rückmeldung)
Destination IPIP des MacsIP des Macs
Port80008001

Receive CommandYesOff
Send–Yes
Send Command–Yes

Schritt 3 – Plugin importieren

  1. Öffne den Ordner grandMA3-Plugin. Darin liegt fertig vorbereitet der Ordner gma3_library.
    • echtes Pult: Ziehe den Ordner gma3_library direkt auf den USB-Stick (ins Hauptverzeichnis). Den Stick ans Pult stecken.
    • grandMA3 onPC: Kopiere die beiden Dateien aus gma3_library/datapools/plugins in den gleichnamigen Ordner im onPC-Datenordner.
  2. Am Pult den Plugins-Pool öffnen, auf ein leeres Feld tippen → Import → APC_Feedback wählen.
  3. Plugin einmal ausführen = starten, nochmal ausführen = stoppen. Bequemer: in der App MA3 → Start feedback plugin.

Nutzt du für die Rückmeldung nicht Line 2, öffne APC_Feedback.lua mit TextEdit und ändere ganz oben OSC_LINE = 2 auf deine Nummer.

4. Verbinden

  1. APC per USB anstecken, dann die App starten. Der richtige MIDI-Port („Control“) wird automatisch gewählt.
  2. Oben die IP-Adresse des Pults eintragen. Port 8000, Listen 8001, Prefix gma3 passen schon.
  3. Auf Connect MA3 klicken.
  4. Unten in der Statusleiste erscheint „MA3 feedback“ mit grünem Punkt → alles läuft.

Wichtig: Nur ein Programm gleichzeitig darf den APC benutzen. Ableton, Logic oder MIDI-Monitore vorher schließen.

5. Benutzen

  • Schnellstart: Beim ersten Start ist schon eine Demo-Belegung geladen: Executoren 201–208 mit Go+, Go−, Toggle, Flash, Off; Fader als Master; Scene-Tasten wechseln die Seite.
  • Belegen: Einen Befehl aus der Liste links auf ein Pad, eine Taste oder einen Fader ziehen.
  • Welcher Executor? Unten links festlegen: By column (Spalte 1 = Basis, Spalte 2 = Basis+1 …), Fixed number oder Auto-increment.
  • Ändern: Element anklicken – rechts im Inspector Befehl und LED-Farben anpassen.
  • Verschieben: belegtes Element auf ein anderes ziehen. Kopieren: dabei ⌘ gedrückt halten.
  • Löschen / testen: Rechtsklick (Trackpad: mit zwei Fingern klicken) → Clear bzw. Simulate.
  • Ohne Hardware testen: Shift + Klick auf die Abbildung drückt eine Taste, Shift + Ziehen bewegt einen Fader.
  • Speichern: File → Save (⌘S). Die letzte Datei öffnet sich beim nächsten Start automatisch.

6. Wenn etwas nicht klappt

ProblemLösung
App lässt sich nicht öffnenSystemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“ (siehe Abschnitt 2).
APC wird nicht gefundenUSB neu einstecken, App neu starten, andere Musik-/MIDI-Programme schließen. Rechts neben den Ports auf ↻ klicken.
Pads reagieren nicht mehrDer APC ist im Drum/Note-Modus. Am Gerät Shift + Scene 5 drücken.
Befehle kommen am Pult nicht anLine 1 prüfen: IP des Macs, Port 8000, Prefix gma3, Receive + Receive Command = Yes. Mac und Pult im selben Netz?
Tasten leuchten nicht / kein „MA3 feedback“Plugin gestartet? Line 2: Port 8001, Send + Send Command = Yes. Firewall: Systemeinstellungen → Netzwerk → Firewall → Optionen → MPC Mapper erlauben.
